# spectrum2-playground

> [!NOTE]
> This project is in a very early stage of development.

**usage:**

requires `bun` and `node`.

- `❯ git clone https://github.com/hastebrot/spectrum2-playground`
- `❯ cd spectrum2-playground/sources/playground-app/`
- `❯ bun install`
- `❯ bun run dev --port 5678`
- `❯ open -a safari --url "http://localhost:5678/"`
